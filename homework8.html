Correlation & regression

Theory

Correlation

Given two random variables X, Y with finite variances σX², σY² > 0, their covariance is Cov(X, Y) = E[(X − μX)(Y − μY)] = E[XY] − E[X]E[Y].
Because covariance depends on measurement units, we standardize both variables (ZX = (X − μX)/σX, ZY = (Y − μY)/σY) to obtain Pearson's correlation coefficient:
ρXY = Cov(X, Y) / (σX σY) = E[ZX ZY], and in a sample {(xi, yi)}i=1..n:
r = SXY / √(SXX SYY), where SXX = Σ(xi − x̄)², SYY = Σ(yi − ȳ)², SXY = Σ(xi − x̄)(yi − ȳ).

By the Cauchy–Schwarz inequality, (Σ(xi − x̄)(yi − ȳ))² ≤ Σ(xi − x̄)² Σ(yi − ȳ)², so −1 ≤ r ≤ 1. Equality |r| = 1 holds if and only if all points lie exactly on a non-horizontal, non-vertical line yi = a + b xi. Furthermore, r is dimensionless and invariant under positive affine rescalings u = αx + c, v = βy + d (αβ > 0), and flips sign if αβ < 0. Crucially, r only measures linear co-movement: r = 0 does not preclude strong nonlinear dependence.

Solving the regression problem for a and b

In linear regression of Y on X, we approximate yi by ŷi = a + b xi and choose (a, b) by Ordinary Least Squares (OLS), minimizing the sum of squared vertical residuals:
S(a, b) = Σi=1..n (yi − a − b xi)².
Setting partial derivatives to zero yields the normal equations:
1) ∂S/∂a = −2 Σ(yi − a − b xi) = 0 ⇒ Σ yi = n a + b Σ xi ⇒ a = ȳ − b x̄.
Substituting a = ȳ − b x̄ centers both variables around their means: S(b) = Σ((yi − ȳ) − b(xi − x̄))².
2) dS/db = −2 Σ(xi − x̄)((yi − ȳ) − b(xi − x̄)) = 0 ⇒ b Σ(xi − x̄)² = Σ(xi − x̄)(yi − ȳ) ⇒
b = SXY / SXX = sXY / sX² = r · (sY / sX).

The Hessian has ∂²S/∂a² = 2n > 0 and determinant 4n SXX > 0 whenever X is not constant, confirming a unique global minimum. Notice two immediate consequences: (i) because a = ȳ − b x̄, the regression line always passes through the centroid (x̄, ȳ); (ii) in standardized coordinates, the fitted line is simply ẑy = r zx. When |r| < 1, a 1-SD shift in X predicts only an |r|-SD shift in Y—the phenomenon of regression to the mean. Moreover, the residual variance decomposes orthogonally as SST = SSR + SSE, giving coefficient of determination R² = SSR / SST = r².

Both regression lines and the geometric average identity

If instead we regress X on Y, x̂i = a' + b' yi, minimizing horizontal squared residuals Σ(xi − a' − b' yi)², swapping the roles of X and Y immediately yields:
b' = SXY / SYY = r · (sX / sY), and a' = x̄ − b' ȳ.
Multiplying the two regression coefficients b and b' eliminates the standard deviations:
b · b' = (r · sY/sX) · (r · sX/sY) = r².
Because b and b' share the exact sign of SXY (and hence of r), their product is always non-negative and the signed geometric mean equals r:
r = sgn(b) · √(b · b') (or equivalently |r| = √(b · b')).

Except when |r| = 1 or r = 0, the two lines are distinct because they minimize different error directions (vertical vs. horizontal). Both cross at (x̄, ȳ). Rewriting the X-on-Y line as y = −a'/b' + (1/b')x (for b' ≠ 0), its slope with respect to x is 1/b' = b / r². Since r² ≤ 1, the X-on-Y line is always steeper than the Y-on-X line when plotted in the (x, y) plane; the angle between them closes as |r| → 1 and opens to 90° (the horizontal line y = ȳ and vertical line x = x̄) when r = 0. Also, since b·b' = r² ≤ 1, |b| and |b'| cannot both exceed 1 simultaneously.

1) Proof that independence implies uncorrelation

Theorem: If X and Y are independent random variables with finite second moments (E[X²], E[Y²] < ∞), then Cov(X, Y) = 0 and ρXY = 0 (X and Y are uncorrelated).
Proof: Independence means the joint distribution factors into the marginals: fXY(x, y) = fX(x) fY(y) in the continuous case (or pXY(x, y) = pX(x) pY(y) in the discrete case; in general P(X ∈ A, Y ∈ B) = P(X ∈ A)P(Y ∈ B)). Therefore, by factorization (Fubini's theorem, valid since E|X|, E|Y| < ∞):
E[XY] = ∬ x y fXY(x, y) dx dy = ∬ x y fX(x) fY(y) dx dy = (∫ x fX(x) dx)(∫ y fY(y) dy) = E[X] · E[Y]
(and identically ΣxΣy x y pX(x) pY(y) = (Σx x pX(x))(Σy y pY(y)) = E[X] · E[Y] in the discrete case).
Substituting into the covariance definition:
Cov(X, Y) = E[XY] − E[X]E[Y] = E[X]E[Y] − E[X]E[Y] = 0.
Hence ρXY = Cov(X, Y) / (σX σY) = 0. ∎

The converse is false: uncorrelation does not imply independence. Let X ~ Uniform(−1, 1) (or X ∈ {−1, 0, 1} with equal probability 1/3) and define Y = X². By symmetry E[X] = 0 and E[XY] = E[X³] = 0, so Cov(X, Y) = 0 and ρXY = 0; yet Y is completely determined by X (for instance P(Y = 1 | X = 1) = 1 ≠ P(Y = 1)). Only in special joint families—most notably the bivariate normal distribution—does ρXY = 0 guarantee independence.

Code

function regress(pairs) {                       // pairs = [[x, y], ...]
  const n = pairs.length;
  const mx = pairs.reduce((s, p) => s + p[0], 0) / n, my = pairs.reduce((s, p) => s + p[1], 0) / n;
  let sxx = 0, syy = 0, sxy = 0;
  for (const [x, y] of pairs) {
    const dx = x - mx, dy = y - my;
    sxx += dx * dx; syy += dy * dy; sxy += dx * dy;
  }
  const b = sxy / sxx, a = my - b * mx;         // Y on X: y = a + b x
  const bp = sxy / syy, ap = mx - bp * my;      // X on Y: x = a' + b' y
  const r = sxy / Math.sqrt(sxx * syy);
  const rGeom = (sxy < 0 ? -1 : 1) * Math.sqrt(b * bp);
  return { n, mx, my, sxx, syy, sxy, a, b, ap, bp, r, rGeom, diff: Math.abs(r - rGeom) };
}

Conclusions

Pearson's r measures the strength and direction of linear association, while the regression slopes rescale r by the ratio of standard deviations: b = r(sY/sX) and b' = r(sX/sY). Because OLS minimizes asymmetric errors—vertical for Y on X, horizontal for X on Y—regression is not symmetric in the two variables, producing two distinct lines whenever 0 < |r| < 1 whose slopes multiply to r².

Finally, independence implies Cov(X, Y) = 0 and r = 0, as shown directly by E[XY] = E[X]E[Y], yet r = 0 only rules out linear dependence. As the parabola preset illustrates, variables can have r = 0 and completely flat regression lines while obeying an exact deterministic relation—and conversely, a large |r| never by itself establishes causality.
