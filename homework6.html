Statistical independence

Theory

Probability

Events A, B are independent iff P(A ∩ B) = P(A)·P(B), equivalently P(A | B) = P(A) when P(B) > 0.
Discrete random variables X, F are independent iff pij = P(X = xi, F = fj) = pi··p·j for every pair (i, j). Equivalently, every conditional distribution P(F | X = xi) equals the marginal P(F), and the same holds with X and F swapped.

Statistics

From n observations, nij is the count of pairs (xi, fj), ni· and n·j are the row and column totals, and nij/n estimates pij. Under H0 (independence) the expected counts are eij = ni··n·j/n, and
χ² = Σij (nij − eij)² / eij, approximately χ² with (R − 1)(C − 1) degrees of freedom for large n (rule of thumb: all eij ≥ 5).
p-value = P(χ²df ≥ observed) = Q(df/2, χ²/2), with Q the regularised upper incomplete gamma function. The strength of the association is measured by Cramér's V = √(χ² / (n·min(R − 1, C − 1))).

A finite sample is never exactly independent. The test asks whether the deviations from the expected counts are larger than what chance alone produces under H0.

Code

function analyse(pairs) {                       // pairs = [[x, f], ...]
  const rows = [...new Set(pairs.map(p => p[0]))].sort(), cols = [...new Set(pairs.map(p => p[1]))].sort();
  const O = rows.map(() => cols.map(() => 0));  // contingency table, built from the raw pairs
  for (const [x, f] of pairs) O[rows.indexOf(x)][cols.indexOf(f)]++;
  const n = pairs.length, r = O.map(a => a.reduce((s, v) => s + v)), c = cols.map((_, j) => O.reduce((s, a) => s + a[j], 0));
  const E = O.map((a, i) => a.map((_, j) => r[i] * c[j] / n));          // expected under independence
  let chi2 = 0; O.forEach((a, i) => a.forEach((o, j) => chi2 += (o - E[i][j]) ** 2 / E[i][j]));
  const df = (rows.length - 1) * (cols.length - 1), p = Qgamma(df / 2, chi2 / 2);
  return { rows, cols, O, E, r, c, n, chi2, df, p, V: Math.sqrt(chi2 / (n * Math.min(rows.length - 1, cols.length - 1))) };
}

Conclusions

The test compares the observed table with the table that independence would produce. A small p-value says that the observed association is unlikely under independence; it does not say how strong the association is (Cramér's V does), and with large n even a tiny deviation gives a small p-value. The opposite also holds: a large p-value means that the data are compatible with independence, not that independence is proved, especially for small n. For the simulated die and coin, independent by construction, about 5% of the runs reject H0 at α = 0.05 by chance alone: press Compute a few times.

Dependence is not causation. χ² is symmetric in the two variables, so it gives no direction, and it ignores other variables. In the Titanic table sex and survival are strongly dependent, but the table does not say that sex alone caused survival: class, age and access to lifeboats are related to both and are not in the table. The same holds for hair and eye colour: they are clearly associated, and the data say nothing about one determining the other; a common underlying factor is a more plausible explanation than a causal link between them. Establishing causality needs a designed experiment (randomisation) or a causal model, not a test of independence.
