Riemann and Lebesgue integration, and the normal CDF

Ex. 1: Riemann and Lebesgue integration

The two approximations

Riemann. Split [a, b] into n cells of width h = (b − a)/n and sum h·f(tk) with tk the left end, the midpoint or the right end of the cell.
Lebesgue. Split the range with levels y0 < … < yN and let Ek = f−1([yk, yk+1)). The simple function s = Σ yk·1Ek (with yN on {f ≥ yN}) satisfies s ≤ f and ∫s = Σ yk·μ(Ek). With D(t) = μ{f ≥ t} we have μ(Ek) = D(yk) − D(yk+1). For nested partitions ∫s increases to ∫f (monotone convergence).

D is computed in closed form for sin x, x², |x − ½|, the two steps and 1/√x, and by bisection on the decreasing branch for sin x / x. Levels are uniform on [min f, max f], and geometric on [1, N] for the unbounded 1/√x. Computing D is what makes this a genuine Lebesgue sum: if f were a black box, the measures would have to be estimated by counting grid points, which is again a Riemann sum.

Code

function riemann(F, n, off) {            // off = 0 left, 0.5 midpoint, 1 right
  const h = (F.b - F.a) / n; let s = 0;
  for (let k = 0; k < n; k++) s += F.f(F.a + h * (k + off));
  return h * s;
}
function lebesgue(F, N) {                // lower Lebesgue sum with N+1 levels
  const y = F.rng ? Array.from({length: N + 1}, (_, k) => F.rng[0] + (F.rng[1] - F.rng[0]) * k / N)
                  : Array.from({length: N + 1}, (_, k) => Math.pow(N, k / N));   // geometric on [1, N]
  const d = y.map(F.D); let s = y[N] * d[N];
  for (let k = 0; k < N; k++) s += y[k] * (d[k] - d[k + 1]);   // y_k * mu(E_k)
  return s;
}

Pathological functions

Dirichlet 1ℚ∩[0,1]. Every cell contains rationals and irrationals, so every lower Darboux sum is 0 and every upper sum is 1: it is not Riemann integrable. Riemann sums depend on the tags: tags k/n give 1, tags k/n + (√2)/(10n) give 0. In floating point every number is rational, so the function cannot be run on doubles at all.
Lebesgue: ℚ∩[0,1] is countable, so it has measure 0, and ∫f = 1·0 + 0·1 = 0.

Thomae f(p/q) = 1/q, f = 0 on the irrationals. It is continuous at every irrational and discontinuous exactly on the rationals, a null set, so by Lebesgue's criterion it is Riemann integrable, with integral 0. With tags k/n, f(k/n) = gcd(k, n)/n, so the Riemann sum is Σ gcd(k, n)/n². The upper Darboux sum uses the smallest denominator in each cell. Lebesgue: for t > 0 the set {f ≥ t} is finite (denominators ≤ 1/t), so D(t) = 0 and ∫f = 0 for any levels.

Both sums go to 0, but slowly and irregularly: for prime n the Riemann sum is about 2/n, for highly composite n it is larger.

Conclusions

Where f is Riemann integrable the two approaches converge to the same value, as they must. For smooth f the midpoint sum is O(n−2), while the lower Lebesgue sum is O(N−1): 0 ≤ ∫f − ∫s ≤ h·μ(domain), because s rounds f down by h/2 on average. Using the middle of each level instead of its bottom would give second order. With a jump at ½ the Riemann error is O(1/n) when ½ is not a node and 0 when it is, whereas the Lebesgue sum is exact for both steps already with N = 1 (levels on the two values). For |x − ½| the Riemann sum is more accurate at equal n.

For 1/√x the midpoint sum converges only like n−1/2, while geometric levels give about (log N)/N: partitioning the range resolves the singularity. The Riemann integral exists here only as an improper integral, the Lebesgue integral exists directly.

The Lebesgue sum needs D, which means knowing the preimages. With a closed form it costs from about the same to about 30 times more than the Riemann sum in the time table (the browser timings are noisy), and for sin x / x every level needs a root-finding, which makes it roughly 70 times slower. The Dirichlet function is the case where only the Lebesgue integral exists, and Thomae's function shows that the two can agree even when f is discontinuous on a dense set.

Ex. 2: Numerical computation of the normal CDF

Why there is no elementary formula

Φ(x) = ∫−∞x φ(t) dt with φ(t) = e−t²/2/√(2π). The integral over ℝ equals 1, but the antiderivative is not elementary. Liouville's theorem, in the form of Rosenlicht (1972): if f and g are rational, with g not constant, then ∫f·eg dx is elementary if and only if f = R′ + R·g′ for some rational R.

Here f = 1 and g = −x²/2, so we would need 1 = R′ − xR.
R = 0 gives 0 ≠ 1. If R had a pole of order k ≥ 1 at a finite point, R′ would have order k + 1 there and xR at most k, so R′ − xR would have a pole, not be 1. So R is a polynomial of degree d ≥ 0, and R′ − xR has degree d + 1 ≥ 1, not constant. No such R exists.

The error function

erf(z) = (2/√π) ∫0z e−t² dt,   erfc = 1 − erf.
Φ(x) = ½·(1 + erf(x/√2)) = ½·erfc(−x/√2)

This is exact, but it only gives the integral a name. erf is defined by erf′(z) = (2/√π)·e−z² and erf(0) = 0, and its values still have to be computed with a series, a continued fraction, a rational approximation or a quadrature rule. Each works in one range of x and fails in another.

Methods

Hybrid. For |x| ≤ 3: Φ(x) = ½ + φ(x)·Σn≥0 x2n+1/(2n+1)!!, a series of positive terms for x > 0, so there is no cancellation. For |x| > 3 the tail Q(x) = 1 − Φ(x) = φ(x)/(x + 1/(x + 2/(x + 3/(x + …)))) is computed with the modified Lentz algorithm, and Φ(−x) = Q(x) directly.
Quadrature. Φ(x) = ½ ± ∫0|x| φ by composite trapezoid (O(h²)), composite Simpson (O(h⁴)) and Gauss–Legendre.
Maclaurin. The alternating series Φ(x) = ½ + (1/√(2π))·Σ (−1)k x2k+1/(2k(2k+1)k!), as in the notes of the assignment.
A&S 26.2.17. A classical approximation with absolute error below 7.5·10−8. 

function series(x) {                     // 1/2 + phi(x) * sum x^(2n+1) / (2n+1)!!
  let t = x, s = x;
  for (let n = 1; Math.abs(t) > 1e-17 * Math.abs(s) && n < 500; n++) { t *= x * x / (2 * n + 1); s += t; }
  return 0.5 + phi(x) * s;
}
function Qcf(x) {                        // tail, x > 0: phi(x) / (x + 1/(x + 2/(x + ...)))
  let f = x, C = x, D = 0;
  for (let k = 1; k < 2000; k++) {
    D = 1 / (x + k * D); C = x + k / C; f *= C * D;
    if (Math.abs(C * D - 1) < 1e-16) break;
  }
  return phi(x) / f;
}
const Phi = x => Math.abs(x) <= 3 ? series(x) : (x > 0 ? 1 - Qcf(x) : Qcf(-x));

Conclusions

The hybrid method has a relative error of about 10−16 at every point tested, including x = −8 where Φ ≈ 6·10−16, because the small tail is computed directly and never as 1 − Φ. It needs about 34 terms of the series at |x| = 3 and about 50 steps of the continued fraction, fewer for larger |x|.

The alternating Maclaurin series is correct near 0 and useless for large |x|: its terms grow up to about ex²/2 (1014 at |x| = 8) while the result is of order 1, so the rounding error is about 10−16·ex²/2. Trapezoid and Simpson converge as h² and h⁴ and Gauss–Legendre reaches machine precision with about 10 nodes, but all three are limited in the tails by the subtraction ½ − ∫. A&S 26.2.17 is the cheapest, and its error is small in absolute terms but not in relative terms far in the tail.

So erf gives an exact representation, but the evaluation still needs a method chosen for the range: a positive series near the origin and a continued fraction or a rational approximation in the tails. Production libraries use the second option (Cody's rational Chebyshev approximations). In the time table the cheapest are A&S and the Maclaurin series, the hybrid method costs a few µs, and Simpson with 200 panels is several times more expensive.
