            For elliptic-curve scalar multiplication, the important one-way property is that
            computing kG is easy while recovering k from G and kG should be hard. A roughly
            balanced set of coordinates can be a useful sanity check, but it is not a proof of
            security. Strong avalanche behaviour and a uniform fixed-length output are properties
            normally associated with cryptographic hash functions. Scalar multiplication is not a
            hash function, so it should not be expected to satisfy the same avalanche criterion.
